## 📋 Project Description

The Car Agency App is a frontend-only project that allows users to search for vehicles using multiple filters:

- Brand  
- Year  
- Price range  
- Number of doors  
- Transmission type  
- Color

All data is handled on the frontend, and results are updated dynamically as the user changes filter options. This is a great exercise in creating interactive search functionality with clean UI updates.

## 📌 Key Features

- Filter cars in real time based on user input  
- Dynamic generation of year options  
- Responsive and user-friendly UI  
- Error messages when no results match the criteria  
- Clean and organized JavaScript structure

## 🚀 How to Run Locally

1. Clone the repository:

```bash

````

2. Navigate to the project folder:

```bash
cd proyectaAgenciaAutos
```

3. Open the `index.html` file in your browser.

> No build tools or installation required — works directly in the browser.
